# Assignment 1: Non-AI Techniques

This assignment contains Python implementations of the following problems using non-AI techniques:

1. Tic Tac Toe
2. N Queens
3. Magic Square

## How to Run

Open a terminal in this folder and run:

```powershell
python ".\Tic Tac Toe\tic_tac_toe.py"
python ".\N Queens\n_queens.py"
python ".\Magic Square\magic_square.py"
```

## Techniques Used

- Tic Tac Toe: Loops, conditions, and board checking logic
- N Queens: Recursion and backtracking
- Magic Square: Mathematical construction methods
